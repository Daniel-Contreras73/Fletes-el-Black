Fundamento

¿Qué es un componente?

Un bloque de código reutilizable con su propio HTML, estilos y lógica en un solo archivo .vue. En vez de repetir el mismo código en varias páginas, lo encapsulas y lo usas donde lo necesites.

Vista (pages)

Página completa. Ej: la página de login, el dashboard.

LoginView.vue DashboardView.vue

Componente (components)

Pieza reutilizable dentro de una página. Ej: una tarjeta, un formulario.

StatCard.vue ShipmentCard.vue

Ejemplo — en vez de escribir el HTML de la tarjeta 4 veces:

<StatCard title="Total fletes" :value="12" color="red" subtitle="registrados" />
<StatCard title="Activos"      :value="5"  color="blue" subtitle="en progreso" />
Componentes

Props — parámetros del componente

Son los datos que el componente recibe desde afuera. Es igual que declarar parámetros de una función.

// En StatCard.vue — declara qué props acepta
const props = withDefaults(
  defineProps<{
    title: string         // obligatorio
    value: string | number  // obligatorio
    color?: 'red' | 'blue'   // opcional (? = opcional)
    subtitle?: string       // opcional
  }>(),
  { color: 'gray' }         // valor por defecto si no llega color
)

Se usan en el template con interpolación o binding:

<p>{{ title }}</p>               <!-- interpolación -->
<p :class="colorClass">{{ value }}</p>  <!-- binding -->
Template

Interpolación — {{ }}

Muestra el valor de una variable dentro del HTML. Los dobles llaves le dicen a Vue "imprime esta variable aquí".

Sin interpolación — texto fijo

<p>title</p>
<!-- muestra: "title" literal -->

Con interpolación — variable

<p>{{ title }}</p>
<!-- muestra: "Total fletes" -->

Ejemplos del proyecto ShipmentCard.vue:

{{ shipment.folio }}       → "FL-001"
{{ statusLabel }}          → "Entregado"
{{ formattedDate }}        → "05 jun. 2026"
$\{{ shipment.totalPrice }} → "$1,200"
Regla: los {{ }} solo van dentro del contenido HTML. Para atributos dinámicos usa : (v-bind).
Formularios

v-model — enlace de inputs

Conecta un input con una variable. Lo que el usuario escribe se guarda automáticamente en la variable, y si la variable cambia el input se actualiza también.

<input v-model="form.email" />
<!-- cuando el usuario escribe, form.email se actualiza solo -->

Archivos donde se usa:

LoginView.vue RegisterView.vue LandingQuotationForm.vue ShipmentsView.vue
ArchivoUso
LoginView.vuev-model="form.email" / v-model="form.password"
ShipmentsView.vuev-model="search" — filtra fletes en tiempo real
AdminShipmentsView.vuev-model.number="newPrice" — convierte a número automáticamente
Template

v-bind (:) — atributos dinámicos

Poner : antes de un atributo HTML lo hace dinámico — su valor viene de una variable en vez de ser texto fijo.

Sin : — texto fijo

<span class="text-green-500">
<!-- siempre verde -->

Con : — variable

<span :class="statusClass">
<!-- cambia según el estado -->

Funciona con cualquier atributo:

:class="variable"       → clase dinámica
:src="urlImagen"       → imagen dinámica
:href="enlace"          → link dinámico
:disabled="loading"    → desactiva botón si loading es true
:style="estiloObj"      → estilos dinámicos

Ejemplo ShipmentCard.vue:

<span :class="statusClass">{{ statusLabel }}</span>
<!-- statusClass es un computed que devuelve bg-green-100 si está entregado, etc. -->
Eventos

v-on (@) — escuchar eventos

El @ es la forma corta de v-on:. Ejecuta una función cuando el usuario hace algo.

EventoCuándo se disparaEjemplo
@clickClic del usuario@click="handleLogin"
@submit.preventEnvío de formulario@submit.prevent="handleLogin"
@inputEl usuario escribe@input="onInput"
@changeCambia valor de select@change="onRoleChange"
@keydown.enterPresiona Enter@keydown.enter="selectIndex"
@blurEl input pierde el foco@blur="onBlur"

El .stop evita que el evento suba al elemento padre:

<!-- ShipmentCard.vue — sin .stop también se dispararía el @click del div padre -->
<button @click.stop="emit('cancel', shipment.id)">Cancelar</button>
Template

v-if — mostrar u ocultar elementos

Muestra un elemento si la condición es true. Si es false, el elemento desaparece del HTML completamente.

<!-- StatCard.vue — solo muestra el subtítulo si viene como prop -->
<p v-if="subtitle">{{ subtitle }}</p>

<!-- LoginView.vue — solo muestra el error si existe -->
<div v-if="error">{{ error }}</div>

<!-- ShipmentCard.vue — solo muestra botón si el flete se puede cancelar -->
<button v-if="canCancel">Cancelar</button>

Con v-else-if y v-else — encadenados:

<div v-if="analyzing">Analizando con IA...</div>
<div v-else-if="quoting">Calculando precio...</div>
<div v-else-if="analyzeError">{{ analyzeError }}</div>
<div v-else>← muestra los resultados</div>
Template

v-for — repetir elementos

Recorre un array y crea un elemento HTML por cada item. Siempre va acompañado de :key.

<!-- ShipmentsView.vue — una fila por cada flete -->
<tr v-for="shipment in filtered" :key="shipment.id">
  <td>{{ shipment.folio }}</td>
  <td>{{ shipment.originCity }}</td>
</tr>

<!-- StepIndicator.vue — un círculo por cada paso -->
<button v-for="n in total" :key="n">{{ n }}</button>
:key — identificador único por elemento. Vue lo necesita para saber qué fila es cuál cuando la lista cambia. Usa siempre el id del objeto.
Script

computed — valores calculados automáticos

Calcula un valor a partir de otras variables. Se recalcula solo cuando esas variables cambian. Tiene caché — si los datos no cambiaron, no recalcula.

Función normal

// Se ejecuta cada vez
// aunque el resultado sea igual
function getColor() {
  return props.color === 'red'
    ? 'text-red-500'
    : 'text-gray-800'
}

computed

// Se recalcula solo cuando
// props.color cambia
const colorClass = computed(() => ({
  'text-red-500': props.color === 'red',
  'text-gray-800': props.color === 'gray'
}))

Ciclo de vida

Hooks — ciclo de vida del componente

Funciones que Vue ejecuta automáticamente en momentos específicos, sin que el usuario haga nada.

// DashboardView.vue — carga datos al entrar a la página
onMounted(() => {
  if (auth.isAdmin) {
    usersStore.fetchAll()       // admin → carga todos los usuarios
  } else {
    shipmentsStore.fetchMine()  // cliente → carga sus fletes
  }
})
// LandingView.vue — arranca y detiene el carrusel
onMounted(() => { timer = setInterval(next, 5000) })
onUnmounted(() => clearInterval(timer))
// sin onUnmounted el carrusel seguiría en memoria aunque el usuario salga
HookCuándo se ejecutaPara qué se usa
onMountedAl aparecer en pantallaCargar datos del backend
onUnmountedAl salir de la páginaLimpiar timers, intervalos
Diferencia con @click: los hooks los ejecuta Vue automáticamente. Los eventos (@click, @input) los dispara el usuario.
Backend

Peticiones HTTP — hablar con el backend

El frontend no puede tocar la base de datos directamente. Le pide los datos al backend mediante peticiones HTTP.

// fetch — forma nativa del navegador
const res = await fetch('/api/quote/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ images, zone })
})
const data = await res.json()  // segundo await — convierte la respuesta a objeto

fetch directo — rutas públicas

Sin token. Para páginas que no requieren login.

LandingQuotationForm.vue AddressAutocomplete.vue

api.ts (axios) — rutas privadas

Con token automático. Para páginas que requieren login.

DestinationsView.vue PaymentsView.vue
Servicios

api.ts — mensajero configurado

Crea una instancia de axios con 3 reglas automáticas para no repetir configuración en cada archivo.

const api = axios.create({
  baseURL: 'http://localhost:3000/api',  // regla 1: siempre va aquí
  withCredentials: true
})

// Regla 2: agrega el token antes de cada petición
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('accessToken')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// Regla 3: si el token expiró (401), pide uno nuevo y reintenta
// Si falla → borra sesión y manda al login

Cómo se usa en las vistas:

import api from '@/services/api'

const { data } = await api.get('/destinations')     // GET
await api.post('/destinations', form.value)          // POST
await api.patch(`/destinations/${id}/default`)      // PATCH
await api.delete(`/destinations/${id}`)              // DELETE
